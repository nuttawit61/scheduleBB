# ตารางงานอาจารย์แพทย์

ภาควิชาเวชศาสตร์การธนาคารเลือด คณะแพทยศาสตร์ศิริราชพยาบาล

ระบบนี้มี 3 ส่วน:

- **หน้าเว็บ** (`index.html` ตารางงาน, `record.html` บันทึกงาน) อยู่บน GitHub Pages
- **Google Sheet** เก็บข้อมูลงานทั้งหมด (ชีต `entries`) และวันหยุด (ชีต `holidays`)
- **Google Apps Script** เป็นตัวกลางให้หน้าเว็บอ่านและเขียน Google Sheet

ในโฟลเดอร์นี้ไม่มีข้อมูลตารางงานเลย ข้อมูลอยู่ใน Google Sheet เท่านั้น และต้องใส่รหัสก่อนจึงจะเห็นข้อมูล

```
teacher-schedule/
├── index.html          หน้าตารางงาน (ปฏิทิน / ตารางรายบุคคล / Export PDF)
├── record.html         หน้าบันทึกและแก้ไขงาน
├── config.js           ใส่ URL ของ Apps Script ที่นี่
├── .nojekyll
├── apps-script/
│   └── Code.gs         โค้ดสำหรับวางใน Apps Script (ไม่ต้องใช้บน GitHub Pages)
└── README.md
```

---

## ขั้นที่ 1: สร้าง Google Sheet

1. เข้า Google Drive แล้วอัปโหลดไฟล์ `ข้อมูลตั้งต้น-ตารางงานอาจารย์.xlsx`
   (อยู่ในโฟลเดอร์ `google-sheet` ข้าง ๆ โฟลเดอร์ github ไม่ได้อยู่ใน repo นี้)
2. ดับเบิลคลิกเปิดไฟล์ แล้วไปที่ **ไฟล์ > บันทึกเป็น Google ชีต**
   (ต้องเป็น Google ชีตจริง ไม่ใช่ไฟล์ .xlsx ที่เปิดดู จึงจะใช้ Apps Script ได้)
3. ตรวจดูว่ามีชีตชื่อ `entries` และ `holidays` และแถวแรกเป็นหัวตารางภาษาอังกฤษ
   ห้ามเปลี่ยนชื่อหัวตาราง แต่เพิ่มคอลัมน์ของตัวเองต่อท้ายได้

## ขั้นที่ 2: ติดตั้ง Apps Script

1. ใน Google ชีตที่สร้างไว้ ไปที่ **ส่วนขยาย > Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ออกทั้งหมด แล้ววางโค้ดจาก `apps-script/Code.gs`
3. แก้ 2 บรรทัดนี้ในส่วน `CONFIG` เป็นรหัสที่ต้องการ

   ```js
   VIEW_KEY: 'รหัสสำหรับดูอย่างเดียว',
   EDIT_KEY: 'รหัสสำหรับบันทึกงาน',
   ```

   - `VIEW_KEY` ให้คนที่ดูตารางได้อย่างเดียว
   - `EDIT_KEY` ให้คนที่บันทึก แก้ไข และลบงานได้
   - ใช้รหัสที่เดายาก อย่างน้อย 10 ตัวอักษร และให้สองรหัสไม่ซ้ำกัน
4. กด **บันทึก** แล้วเลือกฟังก์ชัน `setup` จากเมนูด้านบน กด **เรียกใช้**
   - ครั้งแรก Google จะขอสิทธิ์ ให้กดอนุญาต (อาจต้องกด "ขั้นสูง" แล้ว "ไปที่โปรเจกต์")
   - `setup()` จะจัดรูปแบบชีตเป็นข้อความ เติม id ให้ทุกแถว และเก็บรหัสไว้ใน Script Properties
5. (ไม่บังคับ) หลังเรียก `setup()` แล้ว ลบรหัสจริงออกจาก `CONFIG` ได้ เพราะเก็บไว้ใน Script Properties แล้ว
   ถ้าจะเปลี่ยนรหัสภายหลัง แก้ได้ที่ **การตั้งค่าโปรเจกต์ (รูปเฟือง) > คุณสมบัติของสคริปต์**

## ขั้นที่ 3: เผยแพร่เป็นเว็บแอป

1. กด **ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่**
2. รูปเฟืองข้าง "เลือกประเภท" เลือก **เว็บแอป**
3. ตั้งค่า
   - **เรียกใช้ในฐานะ:** ฉัน
   - **ผู้ที่มีสิทธิ์เข้าถึง:** ทุกคน
4. กด **ทำให้ใช้งานได้** แล้วคัดลอก **URL เว็บแอป** (ลงท้ายด้วย `/exec`)

> ตั้งเป็น "ทุกคน" ได้ เพราะทุกคำขอต้องมีรหัสที่ถูกต้อง ถ้าไม่มีรหัส Apps Script จะไม่ส่งข้อมูลให้

**ถ้าแก้โค้ดใน Code.gs ภายหลัง** ต้องไปที่ **ทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > ✎ แก้ไข > เวอร์ชัน: เวอร์ชันใหม่ > ทำให้ใช้งานได้**
URL จะยังเป็นอันเดิม

## ขั้นที่ 4: ใส่ URL ใน config.js

เปิดไฟล์ `config.js` แล้ววาง URL ที่ได้จากขั้นที่ 3

```js
window.APP_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec'
};
```

ทดสอบได้ทันทีโดยดับเบิลคลิกเปิด `index.html` ในเครื่อง แล้วใส่รหัส

## ขั้นที่ 5: อัปโหลดขึ้น GitHub และเปิด GitHub Pages

1. สร้าง repository ใหม่ใน GitHub เช่น `teacher-schedule`
2. กด **Add file > Upload files** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (รวมโฟลเดอร์ `apps-script` และไฟล์ `.nojekyll`)
   แล้วกด **Commit changes**
3. ไปที่ **Settings > Pages**
   - **Source:** Deploy from a branch
   - **Branch:** `main` / `(root)` แล้วกด Save
4. รอ 1–2 นาที จะได้ลิงก์แบบ `https://<ชื่อผู้ใช้>.github.io/teacher-schedule/`

GitHub Pages แบบฟรีต้องใช้ repository สาธารณะ ซึ่งไม่เป็นปัญหา เพราะใน repo มีแค่โค้ดกับ URL ของ Apps Script
ข้อมูลตารางงานอยู่ใน Google Sheet และต้องใช้รหัสจึงจะอ่านได้

## การใช้งาน

- เปิดเว็บครั้งแรกจะถามรหัส ติ๊ก "จำรหัสไว้ในเครื่องนี้" เพื่อไม่ต้องใส่ทุกครั้ง
- ปุ่ม **↻ รีเฟรช** ข้างแท็บ ดึงข้อมูลล่าสุดจาก Google Sheet (และรีเฟรชเองเมื่อกลับมาที่หน้าเว็บหลังผ่านไป 1 นาที)
- ใช้รหัส `VIEW_KEY` จะไม่เห็นปุ่มบันทึกงานและปุ่มแก้ไข
- **ออกจากระบบ** อยู่ท้ายหน้า
- แก้ข้อมูลใน Google Sheet โดยตรงได้เลย กดรีเฟรชที่หน้าเว็บก็จะเห็น
  - วันที่ใช้รูปแบบ `2026-10-16` (ค.ศ.) หรือ `16/10/2569` ก็ได้
  - คอลัมน์ `who` ใส่รหัสอาจารย์ คั่นด้วยจุลภาค: `AJ` เจนจิรา, `AK` กุลวรา, `APAO` ปวริศร์, `AS` ศศิจิต
  - เพิ่มแถวใหม่ในชีตโดยปล่อย `id` ว่าง แล้วเรียก `setup()` อีกครั้งเพื่อเติม id
- เพิ่มวันหยุดในชีต `holidays` (คอลัมน์ `date`, `name`)

## แก้ปัญหา

| อาการ | สาเหตุที่พบบ่อย |
|---|---|
| ขึ้น "ยังไม่ได้ใส่ URL ของ Apps Script" | ยังไม่ได้แก้ `config.js` |
| ขึ้น "รหัสไม่ถูกต้อง" | ยังไม่ได้เรียก `setup()` หรือพิมพ์รหัสไม่ตรงกับ Script Properties |
| ขึ้น "Apps Script ตอบกลับไม่ถูกต้อง" | URL ผิด (ต้องลงท้าย `/exec`) หรือตั้ง "ผู้ที่มีสิทธิ์เข้าถึง" ไม่ใช่ "ทุกคน" |
| แก้ Code.gs แล้วไม่เปลี่ยน | ยังไม่ได้ทำให้ใช้งานได้เป็น "เวอร์ชันใหม่" |
| เพิ่มอาจารย์ใหม่ | แก้ `TEACHER_NAMES` ใน Code.gs และ `TEACHERS` / `ORDER` ใน index.html และ record.html |
