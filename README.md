# ตารางงานอาจารย์แพทย์

ภาควิชาเวชศาสตร์การธนาคารเลือด คณะแพทยศาสตร์ศิริราชพยาบาล

ผู้ใช้ทุกคนเข้าสู่ระบบด้วยบัญชีของตัวเอง (ชื่อผู้ใช้ + รหัสผ่าน)
ข้อมูลงานและบัญชีผู้ใช้เก็บใน Google Sheet (รหัสผ่านเก็บแบบเข้ารหัสทางเดียว ไม่มีใครเปิดดูรหัสจริงได้)

---

## ติดตั้ง (ทำครั้งเดียว ประมาณ 15 นาที)

### 1. ทำ Google Sheet

1. อัปโหลดไฟล์ `ข้อมูลตั้งต้น-ตารางงานอาจารย์.xlsx` ขึ้น Google Drive
2. เปิดไฟล์ แล้วกด **ไฟล์ > บันทึกเป็น Google ชีต**

### 2. ใส่โค้ด

1. ใน Google ชีต กด **ส่วนขยาย > Apps Script**
2. ลบโค้ดเดิมออก วางโค้ดจากไฟล์ `apps-script/Code.gs` แล้วกด **บันทึก** (💾)
3. ด้านบน เลือก `setup` แล้วกด **▶ เรียกใช้**
   ถ้า Google ขอสิทธิ์ ให้กดอนุญาต (ถ้าขึ้นคำเตือน กด "ขั้นสูง" > "ไปที่โปรเจกต์")
4. ดูที่ **บันทึกการดำเนินการ (Execution log)** ด้านล่าง จะมีชื่อผู้ใช้ `admin` และ **รหัสชั่วคราว** ใช้รหัสนี้เข้าสู่ระบบครั้งแรก ระบบจะให้ตั้งรหัสผ่านใหม่ทันที
   ถ้าไม่เห็นรหัส: กลับไปที่หน้า Google Sheet แล้วรีเฟรช จะมีเมนู **ระบบตารางงาน > ออกรหัสชั่วคราวให้ admin** กดแล้วรหัสจะเด้งขึ้นมาบนจอ

### 3. เปิดใช้เป็นเว็บแอป

1. กด **ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่**
2. ประเภท: **เว็บแอป**
3. เรียกใช้ในฐานะ: **ฉัน** และผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
4. กด **ทำให้ใช้งานได้** แล้วคัดลอกลิงก์ที่ลงท้ายด้วย `/exec`

### 4. ใส่ลิงก์ในไฟล์ config.js

เปิด `config.js` ด้วย Notepad แล้ววางลิงก์จากข้อ 3 แทนข้อความ `PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE` แล้วบันทึก

```js
API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec'
```

### 5. อัปขึ้น GitHub

1. สร้าง repository ใหม่ ตั้งเป็น **Public**
2. กด **Add file > Upload files** ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป แล้วกด **Commit changes**
3. ไปที่ **Settings > Pages** เลือก Branch: `main` แล้วกด **Save**
4. รอ 1–2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/` ส่งลิงก์นี้ให้ทุกคน

## หมายเหตุ

- ถ้าแก้ข้อมูลใน Google Sheet โดยตรง กดปุ่ม **↻ รีเฟรช** ที่หน้าเว็บก็จะเห็น
- ถ้าแก้โค้ดใน Apps Script ต้องกด **ทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้ > ✎ > เวอร์ชันใหม่ > ทำให้ใช้งานได้** ลิงก์เดิมใช้ต่อได้
- หน้าเว็บจะ**ออกจากระบบอัตโนมัติเมื่อไม่มีการใช้งาน 30 นาที** (ก่อนออก 1 นาทีจะมีกล่องเตือนพร้อมปุ่ม "ใช้งานต่อ") เปลี่ยนจำนวนนาทีได้ที่ `IDLE_MINUTES` ใน `config.js` ใส่ `0` เพื่อปิด

## บัญชีผู้ใช้และรหัสผ่าน

**ผู้ใช้สมัครและตั้งรหัสผ่านเอง** ที่หน้า `register.html` (กด "สมัครใช้งาน" ใต้ช่องเข้าสู่ระบบ) แล้วรอผู้ดูแลระบบอนุมัติ

- **ผู้ดูแลระบบ:** กดชื่อของตัวเองที่มุมขวาบน (ถ้ามีคำขอค้าง จะมีตัวเลขสีเหลืองแจ้ง) แล้วจัดการที่ "คำขอรออนุมัติ"
  - คำขอสมัคร: เลือกสิทธิ์ แล้วกด **อนุมัติ** หรือ **ปฏิเสธ**
  - คำขอตั้งรหัสใหม่ (ลืมรหัสผ่าน): ตรวจสอบกับเจ้าของบัญชีก่อน แล้วกด **อนุมัติรหัสใหม่** หรือ **ไม่อนุมัติ**
  - **ผู้ใช้ลืมรหัสและเข้าไม่ได้ (ทางลัด):** ในตาราง "ผู้ใช้ทั้งหมด" กด **ออกรหัสชั่วคราว** ที่ชื่อผู้ใช้ → ยืนยัน → ระบบแสดงรหัสครั้งเดียว กดคัดลอกแล้วส่งให้เจ้าของบัญชี ผู้ใช้เข้าสู่ระบบด้วยรหัสนี้แล้วระบบให้ตั้งรหัสของตัวเองทันที (รหัสเดิมใช้ไม่ได้ทันที และบันทึกลงประวัติการใช้งาน)
  - ผู้ดูแลดูรหัสผ่านจริงของผู้ใช้ไม่ได้ ระบบเก็บรหัสแบบเข้ารหัสทางเดียว ใช้การออกรหัสชั่วคราวแทน
  - ในตาราง "ผู้ใช้ทั้งหมด" เปลี่ยนสิทธิ์ ปิด/เปิดใช้งาน หรือลบบัญชีได้ และมีปุ่มคัดลอกลิงก์หน้าสมัครใช้งานไว้ส่งให้ผู้ใช้
- สิทธิ์มี 3 แบบ: **ผู้ดูแลระบบ** · **บันทึกและแก้ไขงาน** · **ดูอย่างเดียว**
- **ลืมรหัสผ่าน:** ผู้ใช้ตั้งรหัสใหม่เองที่ `register.html#forgot` แล้วแจ้งผู้ดูแลให้อนุมัติ ระหว่างรออนุมัติ รหัสเดิมยังใช้ได้
- ทุกคนเปลี่ยนรหัสผ่านของตัวเองได้ที่หน้า `account.html`
- ใส่รหัสผิด 5 ครั้งติดกัน บัญชีจะถูกล็อก 15 นาที
- งานที่บันทึกจะมีชื่อผู้บันทึก/ผู้แก้ไขล่าสุดในชีต `entries` คอลัมน์ `createdBy` และ `updatedBy`
- **ผู้ดูแลลืมรหัส:** ในหน้า Google Sheet กดเมนู **ระบบตารางงาน > ออกรหัสชั่วคราวให้ admin** (หรือรันฟังก์ชัน `resetAdmin` ใน Apps Script)
- อย่าแก้ช่อง `salt`, `hash`, `reset…`, `pwChangedAt` ในชีต `users` ด้วยมือ

## ชื่อผู้ใช้และประวัติการใช้งาน

- หน้าตารางงานแสดง "เข้าสู่ระบบโดย ชื่อ-นามสกุล" ใต้หัวเรื่อง และในรายละเอียดงานแสดงว่าใครบันทึก ใครแก้ไขล่าสุด
- แก้ชื่อ-นามสกุลของตัวเองได้ที่หน้าบัญชีผู้ใช้ (ผู้ดูแลแก้ชื่อของคนอื่นได้ด้วยปุ่ม "แก้ชื่อ")
- **หน้าประวัติการใช้งาน (`log.html`)** สำหรับผู้ดูแลระบบ เข้าจากลิงก์ "ประวัติการใช้งาน" ท้ายหน้าตารางงาน หรือที่หน้าบัญชีผู้ใช้
  - บันทึกการเพิ่ม/แก้ไข/ลบงาน (แสดงค่าเดิม → ค่าใหม่ ทีละช่อง), การจัดการบัญชี และการเข้าสู่ระบบ พร้อมวันที่และเวลา
  - กรองตามประเภท ผู้ใช้ ช่วงวันที่ ค้นหาข้อความ และส่งออก CSV ได้
  - ข้อมูลเก็บในชีต `logs` (ระบบสร้างให้เอง) อย่าแก้หรือลบแถวในชีตนี้ถ้าต้องการเก็บเป็นหลักฐาน
  - ถ้าอยากให้ผู้มีสิทธิ์ "บันทึกและแก้ไขงาน" ดูประวัติได้ด้วย แก้ `LOG_VIEWERS: ['admin', 'edit']` ใน Code.gs
  - ถ้าไม่ต้องการเก็บประวัติการเข้าสู่ระบบ แก้ `LOG_LOGINS: false`

## ปฏิทินภาระงานสอน

หน้า `teaching.html` (ปุ่ม "ปฏิทินการสอน →" ในหน้าตารางงาน) แสดงเฉพาะงานสอน ทุกบัญชีเปิดดูได้ และใช้การเข้าสู่ระบบร่วมกับหน้าตารางงาน

- งานสอน = งานที่ช่อง "ประเภท" มีคำว่า "สอน" (เช่น สอน, สอนบรรยาย) ถ้าใช้ชื่อประเภทอื่น กด "นับเป็นงานสอน" แล้วติ๊กเพิ่มได้ (จำไว้แยกแต่ละเครื่อง)
- แท็บ **ปฏิทิน** และ **รายการสอนรายเดือน** (พิมพ์หรือบันทึก PDF ได้) พร้อมชั่วโมงสอนรายเดือนและทั้งปีงบประมาณ (ต.ค.–ก.ย.) ของแต่ละท่าน
- นับชั่วโมงแบบเดียวกับหน้าตารางงาน: ไม่นับงานที่เลื่อน/ขัดข้อง/ยกเลิก งานสอนร่วมนับเต็มให้ทุกท่าน
- ไม่ต้องแก้ Code.gs — เพิ่ม/เปลี่ยนอาจารย์ต้องแก้ TEACHERS ใน `teaching.html` ด้วย

## วันลาของอาจารย์

บันทึกที่หน้า `leave.html` (แยกจากหน้าบันทึกงาน · ปุ่ม "วันลา →" ในหน้าตารางงาน หรือ "＋ บันทึกวันลา" ใต้รายละเอียดวันในปฏิทิน · แก้ไขได้จากปุ่ม ✎ แก้ไข ที่กล่องวันลาในปฏิทิน หรือรายการ "วันลาที่บันทึกไว้") ผู้มีสิทธิ์บันทึกงานเป็นผู้บันทึกได้ ทุกบัญชีเห็นวันลาในปฏิทิน

- เลือกอาจารย์ ประเภทการลา วันที่ (ลาหลายวันใส่ "ถึงวันที่") และช่วงที่ลา: **ทั้งวัน / ครึ่งวันเช้า / ครึ่งวันบ่าย / ระบุเวลา**
- **ลงงานในวันที่อาจารย์ลาได้** (เช่น ลงภาระงานไว้ก่อนอาจารย์ขอลา) — ฟอร์มบันทึกงานจะขึ้นกรอบเตือน "อาจารย์ลาในช่วงนี้" และต้องกด **บันทึกทั้งที่อาจารย์ลา** อีกครั้ง งานนั้นจะขึ้นเตือน ⛔ "อยู่ในช่วงวันลา" ในปฏิทินและตารางรายบุคคล
- **ลาทั้งวัน** = เตือนทุกงานของวันนั้น · **ลาครึ่งวันเช้า** = เตือนงานก่อน 12.00 น. · **ลาครึ่งวันบ่าย** = เตือนงานตั้งแต่ 12.00 น. (เปลี่ยนเวลาแบ่งได้ที่ `LEAVE_HALF_SPLIT` ใน Code.gs) · **ระบุเวลา** = เตือนงานที่ทับช่วงนั้น
- งานที่สถานะเป็น ขัดข้อง / เลื่อน / ยกเลิก ไม่เตือน · งานที่มีอาจารย์หลายท่าน ถ้าท่านที่ลาไม่ได้ไป ให้ตั้ง "สถานะรายบุคคล" ของท่านเป็น ขัดข้อง
- นำเข้าจาก Excel ลงงานในวันลาได้ตามปกติ
- ถ้าบันทึกวันลาทับงานที่มีอยู่แล้ว ระบบให้บันทึกได้ (กดยืนยันอีกครั้ง) แต่งานนั้นจะขึ้นเตือน ⛔ "อยู่ในช่วงวันลา" ในปฏิทินจนกว่าจะแก้สถานะหรือเวลา
- `index.html`, `record.html`, `leave.html` เป็นโค้ดเดียวกัน ต่างกันแค่ `<title>` และ `const PAGE` ('main' / 'form' / 'leave') — แก้ไฟล์หนึ่งต้องแก้ทั้ง 3 ไฟล์
- ข้อมูลเก็บในชีต `leaves` (ระบบสร้างให้เอง) การเพิ่ม/แก้/ลบวันลาบันทึกในประวัติการใช้งาน

## นำเข้าจาก Excel (ผู้ดูแลระบบ)

หน้า `import.html` (เมนูผู้ดูแลระบบในหน้าบัญชีผู้ใช้ > นำเข้าจาก Excel) ใช้นำไฟล์แบบบันทึก TM-QM-F-092 ที่ผู้ประสานงานกรอก (.xls หรือ .xlsx ชีตละอาจารย์ละเดือน) เข้าระบบ

1. เลือกไฟล์ ระบบอ่านไฟล์ในเบราว์เซอร์ (ยังไม่บันทึกอะไร) ชีตของอาจารย์ที่ไม่มีในระบบจะข้ามไป
2. ตรวจ 5 แท็บ: **เพิ่มใหม่**, **แก้ไข** (ค่าเดิม → ค่าตามไฟล์), **ตรงกันแล้ว**, **ไม่มีในไฟล์** (แสดงเท่านั้น ไม่ลบ), **คำเตือน** เอาเครื่องหมายถูกออกจากรายการที่ไม่ต้องการ
3. กด "นำเข้า" แล้ว "ยืนยัน" ทุกรายการบันทึกลงประวัติการใช้งาน (ป้าย "นำเข้าจาก Excel")

กติกา: งานร่วมที่พิมพ์ซ้ำในหลายชีตรวมเป็นงานเดียว (สถานะต่างกันเก็บเป็นสถานะรายบุคคล) · จับคู่งานเดิมจากวันที่ + อาจารย์ + ชื่องาน + เวลาเริ่ม · แก้เฉพาะช่องที่ไฟล์มีค่าและไม่ตรงกัน · งานออนไลน์/ไฮบริดที่บันทึกจากหน้าเว็บจะไม่แก้ช่องสถานที่ · ถ้ามีคนแก้งานนั้นหลังจากเปิดตรวจ ระบบจะข้ามไม่เขียนทับ

ไฟล์ที่เกี่ยวข้อง: `import.html`, `assets/import-core.js`, `assets/xlsx.full.min.js` (SheetJS 0.20.3, Apache-2.0, โหลดเฉพาะตอนเลือกไฟล์) และ action `import_entries` ใน Code.gs (ผู้ดูแลระบบเท่านั้น) — เพิ่ม/เปลี่ยนอาจารย์ต้องแก้ TEACHERS ใน `import.html` ด้วย
